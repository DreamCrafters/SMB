## Особенности Claude Code

- Общие правила SMB и обязательные маршруты находятся в импортированном `AGENTS.md`; тематические файлы в `docs/agent-instructions/` читать по условиям задачи, не импортировать все сразу.
- Использовать доступный Claude skill `smb-monitor-project`. Локальное ревью стандартов и соответствия спецификации выполняет `review-standards-spec`; не подменять его облачной командой `/code-review`.
- Упоминания Codex и его инструментов в общих правилах не требуют запускать Codex из Claude или восстанавливать отсутствующие инструменты. Выполнять требования доступными эквивалентными средствами; недоступную проверку честно обозначать.
- Изменять проектные правила в `AGENTS.md` и соответствующих `docs/agent-instructions/*.md`, чтобы они оставались общими для обоих клиентов. Особенности только Claude хранить здесь.

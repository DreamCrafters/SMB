# Поручения генерального директора

Раздел содержит поручения, задачи, распоряжения и приказы сотрудникам. Гендиректор
создаёт и исправляет поручения, принимает результат или возвращает на доработку.
Исполнитель видит только свои наступившие поручения в работе или на доработке,
может сохранять промежуточный результат и отправлять поручение на проверку.
Комментарий обязателен при изменении и смене статуса.

В `Учётные записи → Должности` у вкладки доступны два режима:
`Отправка и контроль исполнения` и `Получение и выполнение`. Те же режимы
доступны в матрице `Доступ по вкладке` и в предпросмотре вкладки. Назначение
выполняет администратор вручную: название и код должности не включают отправку
автоматически. Режим хранится в server-owned capabilities должности и сохраняется
при изменении других вкладок или административного флага. При объединении
должностей право отправки даёт режим контроля; выполнять вместо получателя он
не позволяет.

При назначении показываются только действующие учётные записи сотрудников
организации, с ФИО и должностями. Ответственный и соисполнители сохраняются по
стабильному `account:<userId>`; кадровые записи и Google Sheets не являются
источником выбора. Backend отклоняет назначения на кадровые ID, включая запросы
напрямую к API. Старые поручения и исторические ФИО сохраняются; существующие
явные кадровые связи позволяют исполнять старое поручение только действующему
аккаунту. Для нового назначения или правки выбирают аккаунт сайта; по фамилии
аккаунт автоматически не подбирается. Отправлять результат на проверку может
ответственный.

В отправке сразу открыта форма из трёх блоков: содержание, исполнители и срок.
Предусмотрены поиск по ФИО/должности и выбор соисполнителей. Дополнительные поля
свёрнуты. В получении отображаются только свои наступившие активные поручения.
Реестр по умолчанию показывает шесть основных колонок; полные колонки и
дополнительные фильтры раскрываются отдельно.

В карточке поручения Совета директоров кнопка `Назначить поручение` открывает
форму с полным содержанием исходного поручения и его текущим сроком. Содержание,
исполнителя и срок можно изменить. Одно поручение СД допускает несколько
самостоятельных назначений сотрудникам. Кнопка доступна при праве отправки
поручений гендиректора и доступе к незавершённому исходному поручению СД.
Источник также можно выбрать в новой форме раздела гендиректора; после
создания связь по ID неизменяема.

В карточке СД таблица перепоручений показывает ответственных, сроки, текущее
состояние и историю назначения, готовности, возвратов и приёмки с комментариями,
авторами и временем. Кнопка `События` раскрывает историю на всю ширину
таблицы отдельной строкой под назначением. Просмотр доступен тем, кто имеет доступ к исходному
поручению СД. В карточке выполненного периода показана та же актуальная история
с отдельной пометкой; сам снимок периода не изменяется, новые назначения из
него недоступны. При смене ответственного прежние события сохраняют его имя.
Завершение дочернего поручения не завершает исходное СД автоматически; после
закрытия исходного СД уже созданные назначения продолжают свой цикл.
Номер нового поручения имеет префикс `ГД-`; номера импортированных поручений
остаются исходными, включая повторяющиеся номера в разные даты.

Поддерживаются разовые и ежедневные, еженедельные, ежемесячные, ежегодные
исполнения. При приёмке сохраняется неизменяемый снимок, затем выбирается первое
следующее исполнение после дня приёмки. Правка не меняет уже принятые снимки.
К поручению можно прикрепить пять PDF по 10 МБ. Удаление из живой карточки
сохраняет документ для истории. Все операции изменения проходят общей
транзакцией с аудитом; ревизии предотвращают перезапись конкурентной правки.

Реестр отображается строками через `ManagedTable`. Фильтры находятся над таблицей
и работают по каждому показанному полю. Длительность и остаток рассчитываются
сервером в рабочих днях с включением обеих границ; суббота и воскресенье
исключаются, отдельный производственный календарь праздников не используется.
Исходные вычисленные значения таблицы остаются в раскрываемой исходной записи.

## Первоначальный перенос

После штатного обновления кода и применения миграции
`085_director_assignments` запустить в **каждом нужном окружении**:

```bash
npm --workspace server run director:import
```

Команда читает только исторические поручения и выводит количество записей и
предупреждения. Источник: `Задачи` книги `1mtV9dvXqPdQ7_kmPgxSfKUzyw2OJyzLe__Wkyz6qMGU`.

После проверки предупреждений:

```bash
npm --workspace server run director:import -- --apply --allow-incomplete
```

`--allow-incomplete` разрешает сохранить неполные исторические записи с явной
пометкой `Требует уточнения`. Исходные поля сохраняются целиком. Такие записи
не выдаются исполнителям до исправления гендиректором. Завершённая история не
переводится в активную из-за отсутствия старого сотрудника в справочнике.

Команда переносит только поручения и снимки завершений. Вкладка `Сотрудники`
больше не читается; кадровые записи, аккаунты, должности и права из таблиц
не создаются и не обновляются. Исходные имена сохраняются в полях истории,
а у вновь импортированных записей ответственного необходимо выбрать из аккаунтов
сайта. Email/MAX при импорте не отправляются.

Повторный запуск не перезаписывает уже перенесённые поручения.
Ключ поручения состоит из книги, листа, исходного номера и даты постановки:
поэтому одинаковые номера с разными датами сохраняются отдельно. Изменение
номера или даты в источнике после переноса считается другой исходной записью;
команда предназначена для первоначального переноса, а не постоянной синхронизации.

## Проверка

Проверить полный цикл с двумя настоящими сессиями: постановка → промежуточный
результат → проверка → доработка → приёмка → история. Дополнительно проверить
отказ доступа другого сотрудника по прямому ID, конфликт двух правок, PDF из
завершённого снимка и сохранность уже принятого периода после правки расписания.
Для поручения, адресованного кадровой записи, изменение связи должно немедленно
закрывать доступ прежнему аккаунту. Прямое назначение учётной записи сохраняет
получателя независимо от последующей привязки к кадровому справочнику. Проверить вкладки и фильтры на мобильном и настольном браузере.

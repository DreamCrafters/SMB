# ЖД Вагоны

Также читать `docs/railway-wagons-section.md`.

- В `ЖД Вагоны` согласование условий логистом и менеджером параллельно: оба этапа требуют `pricingStartedAt`, следующий этап требует обеих отметок одобрения. Отклонение любым согласующим снимает `pricingStartedAt`, `logisticsApprovedAt` и `managerApprovedAt`, возвращая заявку сотруднику по РЖД. Проверять доступность этапа под блокировкой строки в общей транзакции с ревизией и audit; одинаковые правила контракта используются сервером и UI.

# Одна организация на один экземпляр сайта

Каждый экземпляр НМОУ Вектор обслуживает ровно одну организацию: пользователь не выбирает бизнес, администратор не управляет бизнес-аккаунтами, а рабочие записи не разделяются по `businessAccountId`. Для другой организации разворачивается отдельный экземпляр сайта со своей БД; это сознательно упрощает права, импорт, аудит и диспетчерские данные ценой отказа от multi-tenant режима внутри одного deployment. При переходе существующая история сохраняется и становится общей историей организации.
